# Dashboard Features

## Dashboard

The `Dashboard` sheet acts as the presentation layer for the workbook.

## Analysis

The `Analysis` sheet contains supporting analytical views and calculations used by the dashboard.

## Pivot Analytics

The workbook uses named PivotTables for restaurant, category, monthly, and state-level analysis. This keeps the dashboard connected to reusable analytical summaries instead of manually maintained chart ranges.

## Control Panel

The `Control_Panel` sheet provides user-facing controls used by VBA procedures to apply and synchronize filters across PivotTables/dashboard views.

## Data Quality

The `Data_Quality` sheet provides a repeatable validation summary so the user can check data integrity before using the dashboard.
