# Project Overview

## Objective

Build a professional Excel-based analytics dashboard for a large Swiggy restaurant/order dataset, combining data preparation, quality validation, interactive reporting, PivotTable analysis, and VBA automation.

## Analytical Flow

```text
Raw Swiggy Data
      ↓
Data Cleaning / Validation
      ↓
Clean Data Table
      ↓
Calculations + Pivot Data
      ↓
PivotTables / Charts
      ↓
Control Panel Filters
      ↓
Interactive Dashboard
      ↓
PDF Report Export
```

## Dataset Scale

- Raw records: 197,430
- Raw columns: 14
- Clean-data table: 197,431 rows including header
- Current duplicate-row check: 28

## Main Analytical Dimensions

- Geography: State, City, Location
- Time: Order Date, Day, Quarter, Week, Month
- Restaurant: Restaurant Name
- Product/menu: Category, Dish Name, Food Type
- Pricing: Price (INR)
- Customer feedback: Rating, Rating Count
